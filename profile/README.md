[FastStream](https://github.com/ag2ai/faststream) is an open-source framework for building **asynchronous web services** that interact with **event streams** — all with a **unified developer experience**.

Whether you use **Kafka**, **RabbitMQ**, **NATS**, **Redis** — FastStream helps you build reactive, high-performance services clean, consistent patterns.

## 🗂️ What You'll Find Here

This organization hosts community-driven projects that complement the core FastStream framework. Explore our repositories to find:

- **Tooling Plugins:** Integrations with monitoring and logging tools.
- **Framework Bridges:** Connectors for other popular web frameworks and ecosystems.
- **Starter Templates:** Pre-configured project templates to kickstart your development.

## 🤝 How to Contribute

We love contributions! Whether you're a seasoned developer or just getting started, there are many ways to get involved:

- Respect the rules: check our [Contrubuting](https://faststream.ag2.ai/latest/getting-started/contributing/CONTRIBUTING/) guidelines.
- Start Small: Look for issues tagged with `good-first-issue` in our repositories
- Improve Documentation: Fix typos, add examples, or improve explanations
- Report Bugs: Help us identify and document issues
- Share Ideas: Suggest new features or improvements
